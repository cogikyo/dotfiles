# Warrant

Every exception names the wrong belief it prevents.
A departure earns its place when following the default would mislead a reader or user.
A preference for a phrase or a clever special case is not enough.

- State the default and the specific wrong belief that following it would create.
- Write rules as a default plus an unless; justify an absolute by the wrong belief a weaker rule would permit.

See: `idiom`, `candor`, `comments`.
